# 🔍 81-Maktab Topilmalar Burosi Telegram Boti

Ushbu loyiha 81-maktab o'quvchilari va o'qituvchilari uchun mo'ljallangan bo'lib, maktab hududida yo'qolgan yoki topib olingan buyumlarni tez va qulay tarzda o'z egalariga qaytarishga yordam beradi.

---

## 🚀 Asosiy imkoniyatlari

- **Yo'qolgan buyumni qidirish:** O'quvchilar yo'qotgan kiyim, kalit, kitob va boshqa buyumlari haqida e'lon qoldirishlari mumkin.
- **Topilgan buyumni ro'yxatga olish:** Topib olingan narsalarning rasmi va tavsifini botga joylash.
- **Tezkor va xavfsiz aloqa:** Topib oluvchi va buyum egasi o'rtasida qulay muloqot.
- **Ma'lumotlar bazasi:** Barcha e'lonlar xavfsiz saqlanadi va tartibga solinadi.

---

## 🛠 Texnologiyalar

Loyiha quyidagi zamonaviy dasturlash vositalari va kutubxonalari yordamida yaratilgan:

- **Python 3.10+** — Asosiy dasturlash tili
- **python-telegram-bot (v20+)** — Telegram Bot API bilan ishlash uchun
- **SQLite3** — Ma'lumotlar bazasini boshqarish uchun
